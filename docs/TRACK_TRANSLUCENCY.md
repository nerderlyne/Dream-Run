# Track translucency

Seeded visual chapters choose ordinary, reality-bleeding or rare ethereal base opacity. Nearby footing is reinforced; nearby stairs, gaps and safe drops have at least 86% base opacity. Patterns are 86–98% opaque and boundaries remain opaque. Distant geometry loses up to nine additional opacity points. Deep sparse void returns to a concrete track; lucky white uses a milky base.

Base and pattern are disjoint tiles rather than stacked transparent floors. The opaque underside has been removed; sidewalls and stair faces remain. Existing lacquer materials use low metallicity and restrained roughness. Alpha updates are cached with a 0.012 threshold and never rebuild geometry. No collision or reward rules change.
